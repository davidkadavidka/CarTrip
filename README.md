# יומן נסיעות – אפליקציה לאנדרואיד

אפליקציית הנהג של מערכת יומן הנסיעות. היא עובדת מול אותו שרת ואותם נתונים כמו מסכי הדפדפן.

**מה יש באפליקציה:**
- **סורק QR מובנה:** מכוונים את המצלמה לקוד שברכב.
- **עבודה בלי קליטה:** אפשר לפתוח ולסגור נסיעה גם בחניה בלי WiFi. הפרטים נשמרים בטלפון ונשלחים לשרת לבד כשחוזרים לטווח.
- **רשימת רכבים ומצבם:** מי בנסיעה ומי פנוי. מתעדכנת בכל חיבור ונשמרת בטלפון.
- **חתימה באצבע, זיהוי נהג חד-פעמי, ותזכורות על נסיעות שנשכחו:** כמו בגרסת הדפדפן.

## בניית קובץ ההתקנה (APK)
הבנייה נעשית אוטומטית ב-GitHub. ה-workflow נמצא בקובץ `.github/workflows/build-apk.yml`.
1. מעלים את התיקייה הזו למאגר (repository) ב-GitHub.
2. בכל עדכון לענף `main`, הבנייה רצה לבד. אפשר גם להריץ אותה ידנית: Actions ← Build Android APK ← Run workflow.
3. בסיום מורידים את `TripLog-APK` מתוך דף הריצה. בתוכו נמצא הקובץ `TripLog.apk`.

כל הגרסאות נחתמות באותו מפתח (`android/app/triplog-signing.keystore`), ולכן עדכון מותקן מעל הגרסה הקודמת בלי למחוק אותה.

## חלוקה לנהגים
**הדרך הפשוטה:**
1. מעתיקים את `TripLog.apk` לתיקייה `static\download\` בשרת של מערכת יומן הנסיעות.
2. נהג עם אנדרואיד שנכנס ל-`http://<כתובת השרת>:8090/app` יראה כפתור **"הורדה והתקנה"**.
3. בהתקנה הראשונה, אנדרואיד מבקש לאשר "התקנה ממקורות לא ידועים" לדפדפן. מאשרים פעם אחת.

**אפשר גם:** לשלוח את הקובץ בוואטסאפ או במייל.

## הגדרה בטלפון
כתובת השרת מוגדרת מראש: `http://10.8.0.106:8090`. אם הכתובת משתנה, מעדכנים אותה במסך הראשי של האפליקציה ← "הגדרות".
בפעם הראשונה הטלפון צריך להיות ב-WiFi של המשרד, כדי לטעון את רשימת הרכבים והעובדים.

## עדכון המסכים
המסכים של האפליקציה הם אותם קבצים שבתיקיית השרת (`triplog/static/app`). אחרי שינוי שם:
```
sh scripts/update-web.sh ../triplog/static
```
ואז מעלים את השינוי ל-GitHub, והבנייה רצה מחדש.
כשמוציאים גרסה חדשה, מעלים את `versionCode` ו-`versionName` בקובץ `android/app/build.gradle`.
